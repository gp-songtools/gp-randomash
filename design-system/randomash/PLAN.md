# Randomash design plan

Use Canvas #eff4f1, Paper #ffffff, Ink #132b29, Graphite #142e2b, Teal #00796b and Citrus #e4bd6c. Outfit carries the display voice. Instrument Sans, shared with GP Mastering, keeps controls readable and gives tempo, energy, prices and seeds tabular figures.

```
Desktop                            Mobile
Brand      Changelog / Settings    Brand  Settings
Headline   Example mix             Headline / Example mix
Genre mix      Prompt              Genre mix
Genre catalog  Results             Genre catalog
Shape sound    History             Shape → Prompt → Results → History

Changelog
Shared header, title and dated notes in one reading column
```

The brief calls for genre exploration, so replace the generated marketing hero with a loadable deep house and neo-soul recipe. Keep example data out of the editable mix until chosen and retain the dry-run default. Use real catalog counts and existing prompt composition. Reserve the strongest action color for loading and generating. Keep all genre families available, with the first two open initially and a single control to open the rest. Put the prompt beside the catalog on wide screens and link to it from the mix for phones. Reuse existing IDs and handlers for model requests, splitting and history. Verify both browser-facing routes at 390px and 1440px and check the hidden bridge separately.
